## 独立代码审查与修复

独立审查发现并已修复：

1. HEIC 编码器隐式继承 EXIF，导致默认清除照片信息失效。现从像素重建无元数据图片，实际读回验证。
2. PDF 带文本页码时不触发扫描正文识别。现分别提取原生文字和图片区域文字，合并并去重；Word 文字恢复路径同步修正。
3. Excel 纯时间单元格调用了错误的日期时间接口。现按日期、时间、日期时间类型序列化。

另修复受限环境中文字体不可用、相对文档路径解析、Word 导出 Markdown 图片链接不可随文件移动等问题。

打包启动检查发现宿主 Poppler 的 ICU 与 Qt 所需 Windows ICU 符号不同。打包列表已排除误收集的 ICU，通过精简 PATH 的独立程序测试确认。

## 已知边界

- Word 格式为 DOCX；旧版 DOC、加密 PDF 需要用户先另存或解密。
- PDF 转 Markdown 以文字为主；PDF 转 Word 的复杂版式需要核对。
- 公式识别针对框选的单条印刷公式，手写和整页复杂公式不是保真识别目标。
- 扫描或含图像的 PDF 勾选识别并导出可编辑文字 Word 时，不保留原始图片及版式，软件会提示。
- 无本机 Word 时 PDF 导出使用基础文字排版，并明确提示不保留图片和复杂版式。
- CSV 不保留工作簿样式和公式；HDR、深度及 Live Photo 动态信息不保证保留。
