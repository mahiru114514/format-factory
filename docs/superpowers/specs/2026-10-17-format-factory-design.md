# 格式转换工厂：Windows 本地工具设计稿

日期：2026-10-17
状态：用户于 2026-10-17 确认设计；第一版已实现，49 项测试及独立 EXE 验证通过。

## 目标

提供中文 Windows 本地工具，将文档、表格、图片转换和文本处理集中到同一界面。默认在本机处理文件，保留原文件；支持批量任务、选择输出文件夹、逐项显示成功或失败及原因。

## 功能范围

1. 文档：TXT、Markdown、Word（DOCX）互转并生成 PDF；PDF 转 Word、Markdown、TXT。文本型 PDF 提取文字，扫描 PDF 进入识别流程。复杂排版转换提供结果检查入口，不承诺完全还原版式。旧版 DOC 不作为第一版原生支持格式。
2. 表格：XLSX 与 CSV 互转；多工作表分别导出 CSV，提供中文编码选择。CSV 保存表格值，不保留工作簿样式和公式本身。
3. 图片：JPG、PNG、WebP、BMP、TIFF、HEIC/HEIF 常见静态图片互转，提供质量及尺寸设置。转换前提示透明背景等目标格式不能保留的特性。
4. 文本处理：支持粘贴 LaTeX 或导入源码，支持从图片、截图及 PDF 识别文字和公式。用户核对、修改后，可直接复制结果，也可保存 TXT。

## 文本处理的核心交互

用户已明确：文本处理的主要目的，是便于用户转换后核对正确并复制使用。

操作顺序：输入或导入 → 识别/转换 → 对照核对 → 编辑修正 → 复制或保存。

- 原始内容和转换结果并排显示；窄窗口上下显示。图片支持放大，PDF 支持切换页码，以便对照。
- 结果放在可编辑的纯文本区域，允许全选、撤销以及手动修正。原始内容保留，重新转换不直接覆盖用户修改，先提示确认。
- 公式输出提供“ LaTeX 源码”和“可读纯文本”两种明确模式。LaTeX 模式复制实际源码；纯文本模式复制可读文本。切换模式产生新的结果，不静默丢弃编辑内容。
- 主操作为“复制全部”，直接将当前编辑后的结果放入系统剪贴板；不要求先保存文件或点击核对确认复选框。
- 选中文字可通过系统复制快捷键或“复制选中”复制；没有选区时该按钮不可用。
- 次操作为“保存 TXT”，保存当前编辑后的结果，默认 UTF-8 编码。
- 复制成功给出短提示；剪贴板暂时不可用时显示失败原因，保留结果并允许重试。
- 没有有效结果时禁用复制和保存；正在识别、识别失败时不将错误信息当作结果复制。
- 识别结果始终由用户核对；“已复制”仅表示剪贴板写入成功，不表示内容已被系统验证正确。

## 窗口结构

侧边栏提供“文档转换、表格转换、图片转换、文本处理”四个入口。文件转换入口使用统一文件列表、目标格式、输出目录和任务进度。文本处理入口以原文对照和结果编辑为中心，复制按钮位于结果区附近。

## 技术方向及依赖

推荐桌面界面配合本地转换引擎，使用统一任务接口，将文档、表格、图片和识别分别封装。与本地浏览器工具相比，更便于文件选择、剪贴板和日常启动；在线网站需要服务器及文件上传，不作为当前方案。

- 文档引擎候选为 Pandoc，Word/PDF 渲染采用本地 Office 或 LibreOffice 适配层，PDF 读取与版式恢复使用独立组件。
- 表格引擎读取工作簿值及工作表结构，CSV 提供分隔符、编码选择。
- 图片引擎使用 Pillow 配合 HEIF 读写组件，显式检查编解码能力。
- 普通文字 OCR 与公式识别分别接入本地引擎；公式模型和中文识别资源可按需安装，未安装时提供明确状态和安装说明，不伪装转换成功。
- 当前环境检测到 Python、Node.js；未从命令路径发现 Pandoc、LibreOffice 或 Tesseract。开发时需要实际检查、准备并验证所选引擎。

## 错误与数据保护

输出文件名冲突时自动生成新文件名，默认不覆盖源文件。失败任务保留原文件并显示原因，不影响其他任务。临时文件在任务结束后清理。依赖缺失、文件损坏、密码保护和格式不支持分别提示。

## 验收重点

- 文档检查中文、标题、列表、表格和可编辑内容；扫描 PDF 检查识别路径。
- 表格检查中文编码、多工作表、空单元格以及长数字的处理。
- 图片检查 HEIC 的实际读写、方向、尺寸和透明背景的目标格式处理。
- 文本检查用户编辑后复制全部及选区，确保内容与编辑区一致，包括 LaTeX 的反斜杠、花括号、多行和 Unicode 字符。
- 检查复制失败可重试、空结果不可复制、转换失败保留输入、重新转换保护修改和 TXT 内容与编辑区一致。
- 软件打包后在 Windows 上验证启动、文件选择、转换、复制及输出路径。
