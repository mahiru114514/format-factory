# Word / WPS 可编辑公式复制

用户已选择：粘贴后保留分式、根号和上下标，并可继续编辑。

现有纯文本复制会丢失公式结构。新增独立的 Office 公式输出，右侧保存并允许修改 LaTeX，复制基于当前编辑内容，不从可读文本反推公式。普通文本和原始文本继续可用。公式截图仍须使用单条公式识别；此功能不替代识别准确性校对。

使用已随应用分发的 Pandoc 本地转换公式为 MathML，提供 HTML 和 Windows MathML 剪贴板格式。同时提供本机已实测的 WPS 原生剪贴板格式，内容为原生 OMML DOCX 数据，生成时无需启动 Office。混合文字与公式采用显式数学定界符；无定界符的输入视为一条公式。转换警告或结构错误必须阻止公式复制，保留编辑器内容和原剪贴板。兼容性由实际安装的 Word / WPS 空白文档粘贴并检查公式对象验证。另提供 DOCX 保存作为兼容出口，不冒称其他版本已验证。

参考 wps-docs-latex 的结构保留思路，不复制该项目无许可证的实现。此次聚焦 Windows 桌面版，手机系统剪贴板另行适配。

验收：分式、带次数根号、上下标、逻辑箭头、带上下界大析取、矩阵括号均保持；修改后复制使用新值；不支持命令与残缺公式不静默降级；旧文本复制、保存及撤销仍可用。
