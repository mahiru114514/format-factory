# 可编辑公式复制 · 0.1.4

适用 Windows 桌面版。本次未改动手机安装包。

## 使用

1. 双击根目录“启动公式识别.cmd”，确认窗口标题为 **格式转换工厂 0.1.4**。该入口默认选择“单条公式识别”和“Word / WPS 可编辑公式”。
2. 公式截图：粘贴或导入图片，框选完整单条公式，再识别。已有 LaTeX：把处理方式改为“LaTeX / 文本整理”，粘贴源码并转换。
3. 右侧显示可校对的 LaTeX。根据左侧原图修改错误，再点击 **复制到 Word / WPS**。
4. 在 Word 或 WPS 文档正文中按 **Ctrl+V**。保留为可编辑公式；不要选择“仅保留文本”。分式、根号、上下标不会被压成普通文字。
5. 选中完整的 LaTeX 片段后可以“复制选中公式”。需要文件时使用“保存公式 DOCX”；“保存 TXT”仍保存源码文字。

无定界符的内容视为一条公式，例如：

```latex
used[t]\iff\bigvee_{i=0}^{5}(slot[i]=t)
```

文字和公式混排时，明确标出公式，例如：

```latex
计算结果为 $\frac{x_1^2}{\sqrt[3]{y}}$，请核对。
```

切换输出选项后，须重新转换才生成新类型结果。已编辑结果不会因切换选项被擅自替换，其复制方式继续对应已有结果。

## 本机兼容性验证

Word **16.0.20430.20092** 和 WPS **12.1.0.28043**：分别通过分式、三次根号、上下标、逻辑箭头、带上下界大析取、括号矩阵和文字混排的实际粘贴测试；检查原生公式对象和保存后的结构，并查看 PDF 排版。

Word 使用 MathML，含直立粗体变量时使用原生 Office 公式 HTML，避免部分 Word 版本将粗体导入为粗斜体；WPS 使用含原生 Office Math 的 DOCX 剪贴板表示。复制和文件转换均在本机执行，无需联网，也不必后台启动 Office。其他软件版本若只粘贴出文字，请使用“保存公式 DOCX”后打开核对。

## 当前边界

- OCR 识别准确性与复制排版是两个步骤；识别出来的变量、箭头、上下标仍需对照原图核对。
- 当前支持公式片段，不是完整 TeX 文档编译器。
- 未知命令、残缺公式、重复上下标会阻止公式复制，保留编辑内容和原剪贴板。
- 已知无法可靠保留的 `array` 列规则、横线、颜色、未经验证的粗体符号组合等排版会明确拒绝；不会无提示删除。支持 `\mathbf{x}` 等拉丁字母和数字的直立粗体；非拉丁粗体或不支持的嵌套字体组合会保留源码并提示。
- 按严格 TeX 范围处理未加括号的数字上下标：`x^12` 表示 `x^{1}2`；如果希望整个 12 为上标，请写 `x^{12}`。
- 系统字体和目标软件会影响间距与字号；不保证像素级还原。
