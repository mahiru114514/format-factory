# 公式同类问题排查 · 0.1.2

日期：2026-10-18。此次排查确认仍有类似情况，已修复文本整理阶段发现的内容丢失；图片识别模型本身仍有误识，不能保证每条公式正确。

## 已复现并修复

| 类型 | 修复前的风险 | 0.1.2 行为 |
|---|---|---|
| 复合分式 | `\frac{a+b}{c+d}` 变成 `a+b/c+d` | 输出 `((a+b)/(c+d))`，保留运算分组 |
| 分式接平方、下标、阶乘 | 可能把后缀错误地作用在分母 | 给整个商增加括号，例如 `((a)/(b))^2` |
| 多次根号 | `\sqrt[3]{x}` 丢失根次 | 输出 `√[3](x)` |
| 向量、横线、点、括号等标记 | 标记被删除，或生成不正常的组合字符 | 保留相关 LaTeX 原文 |
| 行列式、分段函数 | 外围结构被当成排版丢弃 | 保留原始环境及内容 |
| 增广矩阵 | `array` 列格式中的分隔线消失 | 保留完整原文，包括 `{r|l}` |
| 带星号的运算符名称 | `operatorname*` 被拆坏 | 正确处理名称并保留后续上下标 |
| 手机端粗体向量 | `\mathbf{x}+x` 被变成 `x+x` | 保留原文，保留向量与标量区分 |
| 手机端转义与换行 | `\_1` 被当成下标，换行后的字母被误认成命令 | 区分字面字符、换行和数学命令 |
| 未完成的分组、未知复杂结构 | 容错解析可能改变内容或删除环境 | 保留原文供核对 |
| 白字透明图片 | 统一铺白底导致公式消失 | 对大面积透明且字迹全为浅色的图片使用深色底，预览与识别一致 |

保留原文意味着可读输出中可能出现 LaTeX 命令。这些内容仍能直接编辑、复制和保存，避免把重要结构静默删掉。

## 实际图片仍存在的误识

实际输入和模型原始输出保存在 `formula-audit/actual-image-results.json`，该目录也包含六张测试图片。

- 用户样例的黑底、白底、白字透明和 JPEG 压缩变体：关系符号、大析取、上下界和数组下标均保留；`used`、`slot` 仍被分成带空格的字母，箭头样式会随图片变化。
- `printed-integral.png`：原图下限为 **0**，模型识别为 **a**。整理层没有删除下限，但无法判断其识别是否正确。
- `printed-fraction.png`：原图是单个分式，模型错误生成重复的数组结构，并混淆 **c/C**。本版保留该输出供核对，没有修复此模型误识。

以上模型误识仍需人工修改。本轮没有引入新模型，也没有上传图片到外部服务。测试通过只能证明列出的回归行为，不能推断所有公式均识别正确。

## 使用修复版

关闭已经打开的旧桌面窗口，再双击项目根目录的“启动格式转换工厂.vbs”。当前桌面包位于 `desktop-formula-fix-v0.1.2/FormatFactory/FormatFactory.exe`，请保留整个文件夹。安卓安装包位于 `mobile/格式转换工厂-安卓测试版.apk`。

公式图片请选择“单条公式识别”，尽量框选完整的单条公式。复杂结构可选择“LaTeX / 原始文本”，逐项核对关系符号、上下界、变量名和分式分组，再复制。手机端公式图片识别需更新转换服务后使用，上传前仍逐次确认。
