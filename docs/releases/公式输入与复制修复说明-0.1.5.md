# 公式输入与复制修复 0.1.5

本次修复 Windows 桌面版，手机安装包未更新。

## 使用方法

双击项目根目录的“启动公式识别.vbs”或“启动公式识别.cmd”，确认窗口标题为 0.1.5。

1. 直接粘贴 LaTeX，或导入公式截图。文本输入时按钮为“转换公式文本”，图片输入时为“识别公式”。
2. 转换后在右侧核对、修改。
3. 输出为“Word / WPS 可编辑公式”时点击“复制到 Word / WPS”；输出为“LaTeX / 原始文本”时点击“复制为 Word / WPS 公式”。
4. 在 Word 或 WPS 文档正文按 Ctrl+V。分式、根号、上下标应成为可编辑公式。

“复制源码”和编辑框中的 Ctrl+C 保留 LaTeX 文字，适合保存源码。所有公式复制使用右侧当前编辑后的完整内容。

## 修复内容

- 公式模式支持直接粘贴 LaTeX，不再因为缺少截图而拒绝转换。工具栏粘贴、文件导入和编辑框粘贴保持公式模式偏好一致。
- 原始文本输出增加明确的可编辑公式复制按钮，区分“复制源码”和“复制公式”。
- 修复 `used[t]\iff\bigvee_{i=0}^{5}(slot[i]=t)` 中大析取符号后出现虚线空方框的问题。原来操作数位置为空，括号内容在外部；现将完整的 `(slot[i]=t)` 放入操作数位置。
- 检查大合取、分式操作数、嵌套括号、尾随 `+Q` 和零宽间距。不确定操作数边界时保留原布局，避免错误归组或制造空操作数。
- 保留重新转换前的编辑确认；切换输出选项不会把现有纯文本结果误当成原始公式。

旧文档里已经粘贴的对象不会自动变化，请从新版重新转换、复制，再替换旧对象。截图识别仍需人工核对；不支持的结构继续明确提示。

## 验证材料

打包目录为 `desktop-input-fix-v0.1.5/FormatFactory/`，请整体移动，保留 `_internal` 文件夹。

同级 `verification/` 保存实际 Word/WPS 粘贴结果、原生验证记录、测试数量和程序 SHA-256。应用目录内 `smoke-result.txt` 记录打包后检查，包括直接粘贴、源码输出的公式复制，以及截图识别后的公式结构检查。
