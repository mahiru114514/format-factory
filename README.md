# 格式转换工厂

Windows 10/11 64 位本地格式转换工具，中文界面。文件和识别内容在本机处理，无须注册或提供 API 密钥。

手机端在独立的 `mobile/` 工程中开发，支持本机优先处理与逐次确认上传。构建、功能范围、Android 测试安装包及 iPhone 编译限制见 [手机版说明](mobile/README.md)；受控联网服务见 [服务说明](mobile_server/README.md)。桌面版使用方法保持如下。

## 开始使用

从 GitHub 获取的是源码，仓库不包含本机已打包程序、开发缓存和大型 ONNX 模型。Windows 首次使用需安装 Python 3.13 64 位，在项目目录运行：

```powershell
.\准备运行环境.ps1
```

脚本创建独立环境、安装固定版本依赖，并下载公式模型。准备完成后使用下面的启动入口；需要生成独立程序时运行 `build.ps1`。手机端和服务端请分别参阅各自目录中的说明。

双击根目录的 **启动格式转换工厂.vbs**（不弹出命令窗口），或 **启动格式转换工厂.cmd**。

本机已准备的桌面版在 `deliverables/desktop-input-fix-v0.1.5/FormatFactory/FormatFactory.exe`，上述启动入口优先打开此版本。标题和左下角实际版本均为 0.1.5。无独立程序时入口自动使用已准备的源码环境启动。`deliverables/` 和 `dist/` 是本地生成目录，不随源码上传。

公式截图可直接双击根目录的 **启动公式识别.cmd**，自动进入文本处理，选中公式模式和“Word / WPS 可编辑公式”输出；也提供不弹出命令窗口的 `.vbs` 入口。普通图片导入时如处于文字识别模式，点击新增的 **识别这张图中的单条公式** 按钮即可切换并识别。请在标题显示 0.1.5 的窗口中测试。

保持修复版文件夹完整，可以整体复制到另一台 Windows 64 位电脑，无须安装 Python。不要单独移动 EXE，旁边的 `_internal` 文件夹包含转换引擎和离线模型。

## 文档转换

选择“文档转换”，添加文件或拖入文件，选择 TXT、Markdown、DOCX 或 PDF，选择保存位置后开始转换。支持批量任务；同名文件自动编号，不覆盖原文件。双击成功项可打开结果。

- TXT、Markdown、DOCX 之间转换，均可生成 PDF。
- PDF 可转 DOCX、TXT 或 Markdown。PDF 转 Markdown 以文字提取为主，不自动恢复标题或表格。
- PDF 默认优先用本机 Microsoft Word 导出，保留更多图片、表格及公式版式。本机 Word 不可用时会使用基础文字排版并显示提示。基础排版不保留图片和复杂版式。
- 扫描 PDF 请勾选“识别扫描 PDF”。当前以中文、英文文字识别为主；复杂公式建议在“文本处理”里单独框选识别。
- 勾选识别后，含扫描图片的 PDF 转 Word 以恢复可编辑文字为目标，原始图片与版式不保留，软件会明确提示。
- PDF 转 Word 无法保证复杂版式完全还原，请核对表格、多栏及公式。
- Word 格式为 `.docx`，不支持旧版 `.doc`。加密 PDF 请先解密并另存。

## 表格转换

- XLSX → CSV：每张工作表分别导出。CSV 只保留数据值，不能保留样式、合并单元格或公式本身。
- 公式使用工作簿中已缓存的计算结果。缺少缓存时会明确提示；先在 Excel 里重新计算并保存，再重新转换。
- CSV → XLSX：默认按文本导入，保留前导零、长编号，以及以等号开头的原始文字。需要计算的列可在 Excel 里再转换为数值。
- 可选择 UTF-8（带 BOM，兼容 Excel）、UTF-8（无 BOM）、GB18030，以及逗号、分号或制表符分隔。

## 图片转换

支持 JPG、PNG、WebP、BMP、TIFF、HEIC/HEIF 常见静态图片互转，支持 iPhone HEIC。GIF、AVIF 可作为输入（取决于本机编解码能力），多帧输入仅转换第一帧并提示。

- 质量设置对 JPG、WebP、HEIC 生效；PNG 是无损编码。
- 最长边设为“保持原尺寸”时不调整尺寸；其他设置按比例缩小，不放大小图。
- 自动校正 EXIF 方向。透明背景转为 JPG、BMP 或 HEIC 时填充白色并提示。
- 默认不保留照片元数据；勾选“保留照片信息”可尽量保留拍摄信息和色彩配置。HDR、深度信息、Live Photo 动态部分不作为保真转换目标。

## 文本处理：核对后复制

1. 粘贴 LaTeX 或普通文字，或导入 TXT、TEX、Markdown、Word、PDF、图片。
2. 截图可通过“粘贴剪贴板”导入。图片或 PDF 支持滚轮缩放、拖动框选识别区域；PDF 可以切换页码。
3. 选择“LaTeX / 文本整理”“图片 / PDF 文字识别”或“公式（图片识别 / LaTeX 转换）”。公式模式支持直接粘贴 LaTeX；截图识别请框选一条清晰的印刷公式，不用于整页公式自动排版。
4. 复制到 Word / WPS 后继续编辑公式，请选“Word / WPS 可编辑公式”。普通文字可选“可读纯文本”，保留源码文字可选“LaTeX / 原始文本”。
5. 点击“转换 / 识别”，对照左侧原文，在右侧直接修改结果。
6. 公式输出时点击“复制到 Word / WPS”，再到文档正文按 Ctrl+V，保留分式、根号、上下标等可编辑结构；原始文本输出时点击“复制为 Word / WPS 公式”也可复制可编辑公式，“复制源码”只复制 LaTeX 文字；普通文字输出时使用“复制全部”或“复制选中”。所有复制均使用**当前编辑后的内容**。混排文字用 `$…$` 标出公式；无定界符时整段视为一条公式。
7. 需要文件时可“保存公式 DOCX”，或“保存 TXT”留存 UTF-8 源码。识别准确性仍需核对；未知或残缺公式、已知无法保留的排版会明确拒绝复制。

PDF 识别处理当前页或框选区域；批量提取整份 PDF 的文字请使用文档转换。重新转换前如果结果有手工修改，程序会先询问是否替换。更换输入不会删除已经编辑的结果。

OCR 和公式识别需要用户核对；低清晰度、手写公式和复杂结构可能识别错误。首次识别需载入本地模型，后续会复用模型。运行时不上传文件或下载模型。

公式修复版保留逻辑运算符、上下界及未知命令；再次导入图片时保留已选择的公式识别模式。黑底截图的细边框会在安全范围内裁除，数学符号使用本机数学字体回退显示。模型仍可能把变量识别成带空格的字母，请在右侧核对后复制。具体样例见 `docs/releases/公式识别修复说明.md`。

0.1.2 补充分式整体分组、根次和复杂数学结构保护，以及透明白字图片可见性修复。无法可靠整理的结构保留原文。实际图片测试仍发现积分下限字符误识和分式结构误识，需要人工核对。详细结果与原始输出见 `docs/releases/同类公式问题排查报告.md`。

0.1.3 修复公式模式入口不明显和版本显示写死的问题；对有上下界、能够可靠对应到单个大逻辑符号的清晰图像，补充析取/合取方向校验；歧义时保留模型结果。本次用户截图已通过真实界面识别、复制和 TXT 保存检查，变量字母间距仍须校对。见 `docs/releases/公式入口修复说明-0.1.3.md`。

0.1.4 新增 Word / WPS 可编辑公式复制和公式 DOCX 保存。支持常见拉丁变量直立粗体，修正数字上下标范围，拦截重复脚本与已知会丢失的排版。已在本机 Word/WPS 中实测，详见 [使用说明](docs/releases/可编辑公式复制说明-0.1.4.md) 和 [验证记录](docs/releases/可编辑公式复制验证-0.1.4.md)。本次未改动手机安装包。

0.1.5 修复公式模式直接粘贴 LaTeX 无法转换的问题，并在源码输出中增加明确的公式复制按钮；修复 WPS 大析取符号后多出虚线空方框。已验证带间距、嵌套括号与后续项的处理，见 [修复说明](docs/releases/公式输入与复制修复说明-0.1.5.md)。旧文档里的公式请从新版重新复制、粘贴。

## 状态与失败处理

每个文件独立显示进度、完成提示或失败原因。转换失败不会阻止其他文件继续；点击“停止后续任务”后，当前文件完成，后续文件取消。正在处理任务时请等待任务结束再关闭窗口。

遇到“完成 · 有提示”或失败，请查看下方详情；鼠标停留在状态文字上也可查看完整信息。

## 源码运行与重新打包

已准备好的独立桌面版不需要执行以下步骤。

开发环境使用 Python 3.13 64 位，依赖固定在 `requirements.txt`。在项目目录运行 `准备运行环境.ps1` 可安装依赖及下载官方公式模型；首次准备需要联网。再运行 `build.ps1` 生成独立桌面版。

运行验证：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest tests -q
```

打包后的快速检查：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
.\dist\FormatFactory\FormatFactory.exe --smoke-test
```

检查报告保存在 EXE 同目录的 `smoke-result.txt`。该检查使用生成的示例文件，验证文档、表格、HEIC、文字/公式识别以及编辑后复制和保存，不读取个人文件。

第三方组件及许可说明见 `THIRD_PARTY.md`。公式引擎的兼容性调整见 `vendor/README.md`。
